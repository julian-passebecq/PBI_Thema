      Describe the look
      
Plain language in, a theme patch out. Only colours, type, container and chart-style keys are accepted, and contrast is checked before anything is applied. This restyles the theme only — it never reads or writes the dashboard spec. For layout work, use Copy AI prompt in the left rail and paste the result into the JSON tab.
